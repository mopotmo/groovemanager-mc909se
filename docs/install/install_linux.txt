Installationsanleitung für den GrooveManager SampleEditor auf Linux
----------------------------------------------------------------------------------------

1. Zunächst muss ein Java Runtime Environment (JRE) auf dem System installiert sein.
   Es wird dringend empfohlen, J2RE 1.5 zu verwenden, auch wenn es derzeit (Anfang
   August 2004) nur als Betaversion verfügbar ist. Eine ältere JRE-Version (mindestens
   1.3) müsste aber auch funktionieren, wenn auch mit einigen Bugs.
   Downloadlinks finden sich unter http://java.sun.com/.
   
2. Es empfiehlt sich, mit dem Befehl
   export PATH=/usr/java/jre/bin:$PATH
   die Java-Ausführungsdatei in die PATH-Variable mit aufzunehmen, wobei anstelle von
   /usr/java/jre/bin der entsprechende Pfad zur Java-Installation angegeben werden
   muss. Dieser kann von System zu System variieren. Ansonsten muss bei jedem der
   folgenden java-Aufrufe der gesamte Pfad zur ausführbaren java-Datei angegeben
   werden.
   
3. Die .zip-Datei sollte neben dieser Installationsanleitung noch die Datei
   install_sse_linux.jar enthalten. Mit dem Befehl
   java -jar install_sse_linux.jar
   kann diese ausgeführt werden. Ein Installer-Dialog sollte erscheinen. Diesem
   einfach Schritt für Schritt folgen.
   
4. Nach erfolgter Installation kann das Programm mit dem Befehl
   java -Djava.library.path=. -jar start.jar
   im gewählten Installationsverzeichnis ausgeführt werden.
